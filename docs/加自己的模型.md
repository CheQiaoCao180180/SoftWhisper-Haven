# 加自己的 Live2D 模型

> 2026-11-18 用「夜兰夏日皮肤」那个包验证过：moc 版本 5、82 个参数、11 个表情，直接就能跑。
> 但原包有两个坑，别人下载的模型大概率也有 —— 这里说清楚怎么处理。

## 一、放哪儿

```
D:\大肥鱼插件\model\<名字>\
    <名字>.model3.json      ← 桌宠靠它找模型
    <名字>.moc3
    <名字>.physics3.json    ← 有就放，没有也能跑
    <名字>.cdi3.json        ← 有就放，调试台靠它列参数
    <名字>.4096\            ← 贴图目录
    Exp3\                   ← 表情（必须有这个子目录名）
    Animation\              ← 动作（必须有这个子目录名）
```

然后把 `settings.json` 的 `Model` 改成：

```json
"Model": "model/<名字>/<名字>.model3.json"
```

## 二、两个坑

### 坑 1：表情和动作必须在子目录里

渲染器是这么找的（`renderer/main.cpp`）：

```cpp
ListFiles(directory + L"Exp3\\*.exp3.json")        // 表情
ListFiles(directory + L"Animation\\*.motion3.json") // 动作
```

**平铺在根目录的 `*.exp3.json` 一律看不见** —— 加载日志里会显示「表情 0」。

### 坑 2：model3.json 里常常没写 Expressions

很多作者导出的 `model3.json` 只有：

```json
{
  "FileReferences": {
    "Moc": "...",
    "Textures": [...],
    "Physics": "...",
    "DisplayInfo": "..."
  },
  "Groups": [
    { "Name": "LipSync",  "Ids": [] },   ← 空！
    { "Name": "EyeBlink", "Ids": [] }    ← 空！
  ]
}
```

**后果**：

| 缺什么 | 表现 |
|---|---|
| `Expressions` 没写 | 表情一个都不能用（哪怕文件夹里有一堆 `.exp3.json`） |
| `Motions` 没写 | 动作播不了 |
| `LipSync.Ids` 是空的 | **说话时嘴不动** |
| `EyeBlink.Ids` 是空的 | **眼睛不眨** |

## 三、一键修

```powershell
# 先看看会做什么（不改文件）
python tools\fix_model.py "D:\大肥鱼插件\model\你的模型" --dry-run

# 真整理
python tools\fix_model.py "D:\大肥鱼插件\model\你的模型"
```

它会：

1. 把根目录的 `*.exp3.json` 搬进 `Exp3\`
2. 把 `*.motion3.json` 搬进 `Animation\`
3. 补 `FileReferences.Expressions`（列全）
4. 补 `FileReferences.Motions.Idle`
5. **自动猜口型和眨眼参数**（从 `cdi3.json` 的参数清单里找）
6. 原件留一份 `.bak`

### 口型 / 眨眼是怎么猜的

```python
口型：ParamMouthOpenY > ParamMouthOpen > ParamJawOpen > ParamMouth > ParamA
眨眼：ParamEyeLOpen + ParamEyeROpen > ParamEyeLClose/RClose > ParamEyeOpen
```

猜不到的话（有些模型参数全是 `Param1`、`Param2` 这种没命名的），脚本会留空，
**不影响显示**，只是说话时嘴不动、眼睛不眨。

## 四、验证

```powershell
# 看能不能加载、有几个参数 / 表情 / 动作
python tools\test_model.py "D:\大肥鱼插件\model\你的模型\你的模型.model3.json"
```

正常的输出长这样：

```
加载 0.64 秒，moc 版本 5，遮罩 15 组用 1 张，贴图约 43 MB，表情 11，动作 1
参数表写好了: params-yelan.txt (82 个)
```

**要看的三处**：

- `moc 版本` —— 4 或 5 都行（SDK 5 支持 3.3~5）
- `表情 N` / `动作 N` —— **0 就说明没写进 model3.json**
- `参数表 ... (N 个)` —— N 太少（个位数）说明模型结构有问题

## 五、已知不兼容的情况

| 情况 | 原因 |
|---|---|
| `moc 版本 3` 以下 | SDK 5 只支持到 3.3 |
| 只有 `.moc`（旧版） | 需要先转成 moc3 |
| `model3.json` 里贴图路径是绝对路径 | 换机器就找不到 |
| 参数全是 `Param1`、`Param2` | 能用，但**动作和表情基本靠不了**，也没法调试 |

## 六、换角色注意

**表情 ID 是跟模型绑死的**。

`大肥鱼` 那套换装（长裙 / 脱鞋 / 眼镜 / 钢盆 / 兔牙）用的是她自己的表情 ID，
换成夜兰之后这些全都不认，`exp` 命令会报「没有这个表情」。

这是正常的 —— 每个模型的作者给表情起的名字都不一样。
