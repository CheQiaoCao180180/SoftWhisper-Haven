# 安装路径清单

> 给第一次装这个项目的人看。**每个文件放哪、放完怎么验证**，都在这一页。
> 别的地方（README / AGENTS.md）讲的是「做什么」，这里只讲「放哪」。

---

## 零、插件根目录可以放在哪

本文所有路径都写成 `%USERPROFILE%\大肥鱼插件`（也就是 `C:\Users\<你>\大肥鱼插件`），
**这只是举例**——放哪都行，只要下面这些子目录结构保持一致。

几个建议：

| 情况 | 建议 |
|---|---|
| C 盘空间紧张 | 放 `D:\大肥鱼插件` 之类，**然后把 C 盘的旧路径用 Junction 指过去**（见下） |
| 只想临时试 | 放桌面也行，但别放太深的路径（有些工具对长路径不友好） |
| ❌ 别放 | 别放进 AI Agent 的沙箱工作区——它会连整个目录一起管，容易误删 |

### 已经搬过位置、但想保留旧路径？

Windows 的 **Junction**（目录联接）可以让旧路径继续能用，不需要管理员权限：

```powershell
# 把 C 盘那个位置删掉（先确认里面没东西了），再指向 D 盘
cmd /c mklink /J "%USERPROFILE%\大肥鱼插件" "D:\大肥鱼插件"
```

对程序来说这是透明的：桌面快捷方式、脚本、源码里写死的 `%USERPROFILE%\大肥鱼插件` 全都照常工作。

> 为什么不用符号链接（`mklink /D`）？那个要管理员权限；Junction 不用，对本地目录效果一样。

## 二、模型放哪（最重要）

### 2.1 先获取

这只模型叫 **DeepSeek-chan（大肥鱼）**，原作者免费配布，**不在仓库里**：

| 项目 | 内容 |
|---|---|
| 原画及拆分 | **神宫凉子**（Kamiya Ryoko） |
| Live2D 建模 | **霓虹猫_NeonNeko** |
| 获取方式 | **VGen** 搜 `kamiya` → 主页 Shop → 免费领取<br>或 B 站搜索「神宫凉子」找配布页面 |

使用时请遵守作者的《免费 Live2D 模型使用须知》，要点：

- ✅ 允许：个人直播、视频创作、二次创作、参数调整
- ❌ 禁止：二次销售、**重新分发模型文件**、冒充原作者
- 📝 公开使用请注明：模型来源 神宫凉子；Live2D 建模 霓虹猫_NeonNeko

### 2.2 放进去

下载解压后，你会得到一个 `DeepSeek` 文件夹，里面有大肥鱼的文件。
**整个文件夹**放到：

```
<插件根目录>\model\DeepSeek\
```

放完应该长这样（路径要一模一样）：

```
model\DeepSeek\大肥鱼.model3.json      ← 这个文件在，就算放对了
model\DeepSeek\大肥鱼.moc3
model\DeepSeek\大肥鱼.physics3.json
model\DeepSeek\大肥鱼.cdi3.json
model\DeepSeek\大肥鱼.4096\texture_00.png
model\DeepSeek\大肥鱼.4096\texture_01.png
model\DeepSeek\大肥鱼.4096\texture_02.png
model\DeepSeek\大肥鱼.4096\texture_03.png
model\DeepSeek\大肥鱼.4096\texture_04.png
model\DeepSeek\Exp3\*.exp3.json        ← 表情，换装靠这个
model\DeepSeek\Animation\*.motion3.json ← 动作
```

### 2.3 验证

```powershell
# 这一句能列出文件就算对
Get-ChildItem "$env:USERPROFILE\大肥鱼插件\model\DeepSeek" -Filter "*.model3.json"
```

或者直接跑 `setup.ps1`，它会打印「模型：<路径>」。

### 2.4 常见错

| 现象 | 原因 |
|---|---|
| 桌宠一片空白 | `大肥鱼.model3.json` 不在 `model\DeepSeek\` 下 |
| 换装/表情没反应 | `Exp3\` 没放进去，或者文件名被改了 |
| 提示找不到贴图 | `大肥鱼.4096\` 文件夹名被改了，或者里面少了 png |
| 能显示但不动 | `Animation\` 缺 IDLE.motion3.json |

## 三、Cubism SDK 放哪

渲染器要链接 Live2D 的 Cubism Core。**SDK 不在仓库里**（Live2D 有专门的许可，得你自己同意才能下）。

### 3.1 下载

到 Live2D 官网：<https://www.live2d.com/sdk/download/native/>

选 **Cubism SDK for Native**，版本 **5-r.5**（或更新的 5.x），同意许可后下载 zip。

### 3.2 放进去

解压后，把**带 `Core` 和 `Framework` 的那一层**放到：

```
<插件根目录>\sdk\CubismSdkForNative-5-r.X\
```

放完应该长这样：

```
sdk\CubismSdkForNative-5-r.5\Core\include\Live2DCubismCore.h    ← 这个文件在，就算放对了
sdk\CubismSdkForNative-5-r.5\Core\lib\windows\x86_64\141\
sdk\CubismSdkForNative-5-r.5\Core\lib\windows\x86_64\142\
sdk\CubismSdkForNative-5-r.5\Core\lib\windows\x86_64\143\
sdk\CubismSdkForNative-5-r.5\Framework\
```

中间那一层文件夹叫什么名字无所谓，`setup.ps1` 会自己找 `Live2DCubismCore.h`。

### 3.3 验证

```powershell
Get-ChildItem "$env:USERPROFILE\大肥鱼插件\sdk" -Recurse -Filter "Live2DCubismCore.h"
```

`setup.ps1` 会打印「Cubism SDK：<路径>」。

## 四、编译：产物落在哪

### 4.1 前置

| 要装什么 | 怎么装 |
|---|---|
| **.NET 10 SDK** | `winget install Microsoft.DotNet.SDK.10` |
| **VS 生成工具（C++）** | `winget install Microsoft.VisualStudio.2022.BuildTools`，装的时候勾「使用 C++ 的桌面开发」 |
| **CMake** | 在 VS Installer 里给生成工具勾上「用于 Windows 的 C++ CMake 工具」 |

### 4.2 一条命令全干

在插件根目录：

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1 -Check
```

它会：检查四样东西 → 编译渲染器 → 编译桌宠和设置工具 → 开一个看不见的桌宠自检一遍。

### 4.3 产物位置（手动编译时）

```powershell
# 渲染器 → renderer\build\Release\l2d-render.exe
cmake -S renderer -B renderer\build -DCUBISM_SDK="<插件根目录>\sdk\CubismSdkForNative-5-r.5"
cmake --build renderer\build --config Release

# 桌宠 → bin\FishPet.exe
dotnet publish src\FishPet\FishPet.csproj -c Release -o bin

# 设置工具 → tools\大肥鱼设置.exe
dotnet publish src\SettingTool\SettingTool.csproj -c Release -o tools `
  /p:PublishSingleFile=true /p:SelfContained=false /p:RuntimeIdentifier=win-x64
```

> ⚠️ **不要把 `renderer\build\` 分享给别人**——里面链接了 Cubism Core 的静态库。
> 每个人都要在自己电脑上编译。

## 五、语音（可选，不做也能用）

不做这一步，桌宠会用系统自带的语音念台词（音质差一点）。

### 5.1 建 Python 环境

```powershell
cd <插件根目录>\audio
python -m venv tts-venv
.\tts-venv\Scripts\python -m pip install edge-tts
```

建完应该长这样：

```
audio\tts-venv\Scripts\python.exe    ← 这个文件在，就算对了
```

### 5.2 批量生成

```powershell
cd <插件根目录>\audio
.\tts-venv\Scripts\python gen_voices_all.py
```

产物落在：

```
audio\voices\<hash>.mp3
```

八种人设 × 约 770 句 = **约 6100 个 mp3，190 MB 左右**。跑完要 1~2 小时（要看网速，edge-tts 要联网）。

### 5.3 只补某几个人设

```powershell
.\tts-venv\Scripts\python gen_voices_all.py --only 狡黠 软恬
```

### 5.4 缓存是怎么配对的

文件名是 `SHA1(音色 + 语速 + 音高 + 音量 + "|" + 文本)[:16]`。
所以：**改了 `Personas.cs` 里的音色/语速/音高/音量，对应的缓存就会失效**，要重跑一遍。

## 六、运行时生成的文件（可以删，会自动重建）

| 文件 / 目录 | 是什么 | 能不能删 |
|---|---|---|
| `cache\` | 贴图解码缓存（`.bgra`）、shader 缓存（`.cso`） | ✅ 能，删了下次启动慢几秒 |
| `audio\voices\` | 语音缓存 | ⚠️ 能，但删了要重新生成 |
| `settings.json` | 你的个人配置 | ❌ 别删，删了所有设置回默认 |
| `api.json` | HTTP 接口的地址和 token | ⚠️ 能删，下次启动会重新生成 |
| `errors.log` | 出问题时先看这个 | ✅ 能 |
| `gifs\` | 录的动图 | ✅ 能 |

## 七、三条路：装完怎么用

### 7.1 接到 AI Agent 上（推荐）

把插件文件夹交给你的 Agent，让它读 `AGENTS.md`。它会通过 MCP 连上桌宠：

```
命令：<插件根目录>\bin\FishPet.Mcp.exe
参数：无（stdio）
```

### 7.2 自己写程序调它

`bin\FishPet.exe` 跑起来之后，会生成 `api.json`：

```json
{ "url": "http://127.0.0.1:39555", "token": "xxxxx" }
```

按这个地址发 HTTP 请求：

```powershell
$api = Get-Content api.json | ConvertFrom-Json
Invoke-RestMethod -Uri "$($api.url)/call/say" -Method Post `
  -Headers @{ Authorization = "Bearer $($api.token)" } `
  -Body '{"text":"〔眯眼笑〕晚上好"}'
```

### 7.3 只用设置工具

双击 `tools\大肥鱼设置.exe`——12 页，能调语音、外观、行为、模型、台词、小剧场、快捷键等等。

## 八、换台电脑要带走什么

| 带走 | 不用带 |
|---|---|
| `settings.json` | `bin\`、`tools\`、`renderer\build\`（到新机器重新编译） |
| `lines\`（如果你改过台词） | `cache\`、`audio\voices\`（会重建） |
| `audio\gen_voices_all.py` | `audio\tts-venv\`（新机器重建） |
| `model\`（如果你有） | `sdk\`（新机器重新下，各自的许可） |

## 九、出问题先看这三样

1. **`errors.log`** —— 最后 20 行，八成有答案
2. **`setup.ps1` 的输出** —— 它会告诉你缺什么、去哪拿
3. **`docs\踩坑记录.md`** —— 如果作者给你了的话（这份是内部笔记，不随仓库分发）

实在不行，把 `errors.log` 最后 30 行发给 Agent。
