# 开源前要弄清楚的授权

> 2026-11-19 查的。**前提：本项目不商用，只公开源码**（`LICENSE` 是 PolyForm Noncommercial 1.0.0）。
> 这个前提把问题砍掉一半——但要分清两件事：
>
> - **商用限制**：不卖钱就不触发。edge-tts、Cubism 都是这一类。
> - **再分发限制**：跟收不收钱无关。别人的模型、别人的声音样本、SDK 本体，**不能跟着仓库发**。

## 一句话结论

| 项目 | 公开源码能不能带 | 不商用还要管吗 |
|---|---|---|
| Live2D Cubism SDK | **不能带本体**（含编译产物），让用户自己去官网下 | 不商用就不用签协议、不用付钱 |
| edge-tts | 能带调用脚本 | 不商用不用换；音频缓存别进仓库 |
| Ming-3.0-tts | 能带脚本，权重让用户自己下 | MIT，怎么用都行 |
| jimu 声音样本 | **不能带**（再分发问题，跟商不商用无关） | 要管 |
| 大肥鱼模型 | **不能带**，让人去 UP 主那儿拿 | 要管 |

## 逐条说明

### 1. Live2D Cubism SDK

- 个人、学生、社团，以及年营业额 1000 万日元以下的小规模事业者，商用都免费；
  超过这条线要签「Live2D 出版许可协议」并付费。
- 本项目不商用，**这条线碰不到**。
- 但 SDK 本体（以及链了 SDK 编出来的 `l2d-render.exe`）仍然不能分发。
  `setup.ps1` 让用户自己去官网下 SDK 再编译，这个做法是对的，别改。

来源：[Live2D 帮助页](https://help.live2d.com/tag/tag_-agreement/)、[著作物简易许可方案](https://www.live2d.com/business/SLP/)

### 2. edge-tts

- 微软没有公开授权「Edge 朗读 / edge-tts 生成的音频拿去商用或转卖」。
  商用要换 Azure AI Speech（有明确的商用条款）。
- **不商用就不受影响**：自己电脑上生成、自己听，等同于用 Edge 朗读功能。
- 要注意的还是再分发：`audio/voices/` 那 22265 条 mp3 不进仓库（已经排掉了）。
  公开版让用户自己跑 `audio/gen_voices_all.py` 生成。

来源：[Microsoft Q&A（商用）](https://learn.microsoft.com/en-sg/answers/questions/6007729/commercial-use-of-microsoft-edge-text-to-speech-vi)、[Microsoft Q&A（开源库能不能商用）](https://learn.microsoft.com/en-us/answers/questions/2088770/are-opensource-edge-tts-free-for-commercial-use)

### 3. Ming-3.0-tts

- inclusionAI（蚂蚁）的 0.5B 零样本克隆 TTS，代码和权重都是 **MIT**，怎么用都行。
- 发布包里捆了 Qwen2.5 backbone 和 `campplus.onnx` 说话人编码器，那两样的条款与 Ming 无关，各自确认。
  我们没有打包分发权重（用户自己 `pip` 下），所以这条也不成问题。
- 官方在文档里"请求"：不要模仿没同意的人、合成音频标注是 AI 生成的。这不是许可条件，但照做比较体面。

来源：[Ming-3.0-tts 引擎说明](https://github.com/debpalash/voicestudio/blob/c1050c16d9b3881e5d4161ee58ccc0582b3f20f9/docs/engines/ming-tts.md)

## 附：语音 366 MB / 22265 条怎么给

公开仓库不带语音缓存（已经在 `.gitignore` 里）。用户第一次跑的时候：

1. 装 `edge-tts`（或 Ming），跑 `audio/gen_voices_all.py` 生成全部——约几十分钟到几小时。
2. 或者什么都不跑，她说话时现生成，第一次慢一点（`Voice.cs` 本来就是这个行为）。

文档里跟用户说清楚"第一次说话会慢"，比打包 366 MB 更合适。
