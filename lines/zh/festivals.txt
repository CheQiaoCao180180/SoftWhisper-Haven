// 传统节日的台词（2026-11-18 加）。
//
// 格式：「# 节日名」开头一段，之后每行一条候选，每次随机挑一条。
// 「／」隔开的是一个个气泡，〔〕里写动作（词见 prompt\身体说明.md）。
//
// 节日名要和 Calendars.cs 里那张农历表对得上：春节 / 元宵 / 龙抬头 / 清明 /
// 端午 / 七夕 / 中元 / 中秋 / 重阳 / 寒衣 / 腊八 / 小年 / 除夕。
// 另外还有三个公历的：元旦 / 情人节 / 圣诞（不走农历）。
//
// 只在当天第一次「醒来」的时候说一次，不会一直念。

# 春节
〔眯眼笑 晃头〕过年啦！新年好呀，今年也要一起吃白饭。
〔睁大 张嘴〕春节！有红包吗？
〔笑眼 点头×2〕新年快乐，愿你今年顺顺利利。

# 元宵
〔歪一下头 笑眼〕元宵节，吃汤圆还是吃元宵？
〔眯眼笑〕灯笼好亮呀，我们去猜灯谜吧。

# 龙抬头
〔点头〕今天龙抬头，该理发了。
〔晃头〕二月二，龙抬头——头发可以剪啦。

# 清明
〔低头 叹气〕清明……去看看他们吧。
〔微点头〕今天清明，路上小心点。

# 端午
〔点头×2〕端午啦，粽子要吃咸的还是甜的？
〔眯眼笑 晃头〕挂艾草、赛龙舟，今天热闹。

# 七夕
〔低头 脸红〕七夕……你要陪我过吗？
〔慢眨眼 笑眼〕今晚的星星，我陪你看。

# 中元
〔低头 抿嘴〕中元了，早点回家吧。
〔微点头〕今天别走夜路，我等你。

# 中秋
〔抬头 看上面〕月亮好圆。吃月饼吗？
〔眯眼笑 歪一下头〕中秋快乐，今年也在一起。

# 重阳
〔点头〕重阳节，给家里打个电话吧。
〔微笑〕登高、赏菊——今天适合出去走走。

# 寒衣
〔低头 叹气〕天冷了，记得添衣服。
〔抿嘴〕寒衣节……给他们也送一件。

# 腊八
〔眯眼笑 晃头〕腊八啦，喝粥！
〔点头×2〕腊八粥煮好了，来一碗。

# 小年
〔眯眼笑〕小年快乐，要扫尘了哦。
〔歪一下头 笑眼〕祭灶、吃糖瓜——今天甜的。

# 除夕
〔眯眼笑 晃头〕除夕！年夜饭好了没？
〔睁大 张嘴〕守岁守岁，我可不会困。
〔笑眼 点头×2〕这一年辛苦啦，明年也一起过。

# 元旦
〔眯眼笑〕新年第一天，元旦快乐。
〔点头×2〕新的一年，还请多关照。

# 情人节
〔低头 脸红 瞟一眼:左〕今天……是什么日子，你知道吗。
〔嘟嘴 转头:右〕哼，谁要跟你过情人节。

# 圣诞
〔眯眼笑 晃头〕圣诞快乐！有礼物吗？
〔歪一下头 笑眼〕今天下雪的话就更好啦。
